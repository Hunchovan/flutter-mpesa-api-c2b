# Contributing to Flutter M-Pesa Integration

Thank you for your interest in contributing to this project! Here are some guidelines.

## 🚀 How to Contribute

1. **Fork the repository**
2. **Create a feature branch** (`git checkout -b feature/amazing-feature`)
3. **Commit your changes** (`git commit -m 'Add amazing feature'`)
4. **Push to the branch** (`git push origin feature/amazing-feature`)
5. **Open a Pull Request**

## 📋 Before You Contribute

- Make sure you have a valid M-Pesa test account
- Test your changes thoroughly on a simulator and real device
- Follow the existing code style
- Update documentation if needed

## 🐛 Reporting Bugs

When reporting bugs, please include:
- Device and OS version
- Flutter SDK version
- Steps to reproduce
- Expected vs actual behavior
- Error logs (if applicable)

## 💡 Feature Requests

Have a great idea? Open an issue describing:
- What you want to add
- Why it's useful
- How you'd implement it

## 📝 Code Standards

- Use proper Dart formatting (`flutter format`)
- Follow Flutter conventions
- Add comments for complex logic
- Test your code changes

## 🔐 Security Issues

For security vulnerabilities, please email directly instead of opening a public issue.

Thank you for contributing! ❤️

# Contribuindo para Flutter M-Pesa Integration

Obrigado pelo seu interesse em contribuir para este projeto! Aqui estão algumas diretrizes.

## 🚀 Como Contribuir

1. **Faça um fork do repositório**
2. **Crie uma branch de feature** (`git checkout -b feature/recurso-incrivel`)
3. **Commit suas mudanças** (`git commit -m 'Adiciona recurso incrível'`)
4. **Push para a branch** (`git push origin feature/recurso-incrivel`)
5. **Abra um Pull Request**

## 📋 Antes de Contribuir

- Certifique-se de ter uma conta de teste M-Pesa válida
- Teste suas mudanças thoroughly em um simulador e dispositivo real
- Siga o estilo de código existente
- Atualize a documentação se necessário

## 🐛 Relatando Bugs

Ao relatar bugs, inclua:
- Dispositivo e versão do SO
- Versão do SDK Flutter
- Passos para reproduzir
- Comportamento esperado vs atual
- Logs de erro (se aplicável)

## 💡 Sugestões de Recursos

Tem uma ótima ideia? Abra uma issue descrevendo:
- O que você quer adicionar
- Por que é útil
- Como você implementaria

## 📝 Padrões de Código

- Use formatação adequada do Dart (`flutter format`)
- Siga as convenções do Flutter
- Adicione comentários para lógica complexa
- Teste suas mudanças de código

## 🔐 Problemas de Segurança

Para vulnerabilidades de segurança, envie um email direto em vez de abrir uma issue pública.

Obrigado por contribuir! ❤️
